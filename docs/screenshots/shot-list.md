# Скриншоты для установки

Скриншоты для раздела «Установка» в README. Файлы — `docs/screenshots/<имя>.png`, ширина 1600 px, светлая тема, macOS. На каждом кадре стрелкой или рамкой акцента `#a35cff` отмечено, куда нажать.

**Перед съёмкой:** на кадрах не должно быть чужих сессий, имён проектов, почты и путей с именем пользователя. Боковую панель со списком сессий закрыть или обрезать; аккаунт — тестовый.

## Куда вставить

В README после каждого шага установки — картинка одной строкой, например:

```markdown
![Вкладка Code в приложении Claude](docs/screenshots/02-claude-code-tab.png)
```

Пока файлов нет, ссылки в README не добавляются, чтобы на GitHub не было битых картинок.
